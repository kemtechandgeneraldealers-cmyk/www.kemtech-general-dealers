# KemTech & General Dealers

Next.js + TypeScript + Tailwind CSS starter website.

## Run in VS Code
1. Install a current supported Node.js LTS release (Node.js 20.9+).
2. Open this folder in VS Code and choose Terminal → New Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Build check
Run `npm run build` before deployment.

## Deploy to Vercel
Push the project to GitHub, sign in at https://vercel.com/, choose Add New → Project, import the repository, and deploy with the detected Next.js settings. New pushes normally trigger deployments.

## Before publishing
Replace all example portfolio content and contact placeholders with true information. Add your own licensed images to `public/images/`. Do not commit `.env.local`, passwords, or API keys. The contact API route is a placeholder and does not send messages.
